# 王智申作品集

王智申的个人视觉设计作品集网站，包含「慢吞」「退潮」「把今天交给旋律」三个完整项目。

线上访问：[wang-zhishen-portfolio.pages.dev](https://wang-zhishen-portfolio.pages.dev/)

## 技术栈

- Vite 7
- 原生 JavaScript、HTML、CSS
- pnpm 11

## 本地开发

```bash
pnpm install --frozen-lockfile
pnpm dev
```

生产构建：

```bash
pnpm build
```

## Cloudflare 部署

```bash
pnpm deploy
```

仓库包含网站源码和全部运行资源。原始设计 PDF 与工作文件体积较大，仅在本地归档，不参与网站构建或部署。
